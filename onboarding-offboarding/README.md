# The Baton-Pass: Data Onboarding and Offboarding

This is an hour-long seminar on the best practices for taking care of your data throughout your data life cycle. In the PPT, we discuss the key philosophy behind data onboarding and offboarding, including what needs to be recorded and when. 

We link out to resources and templates to help you implement these practices effectively.
